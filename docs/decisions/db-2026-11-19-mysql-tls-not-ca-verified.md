# MySQL TLS is required but the certificate is not CA-verified

- **Who:** Sabari
- **Date:** 2026-11-19
- **What:** MySQL rejects unencrypted connections (`require_secure_transport=ON`, TLS 1.2/1.3 only).
  The API connects with `sslMode=REQUIRED`: the connection is always encrypted, but the server
  certificate (generated by MySQL on first start) is not checked against a CA.
- **Why:** Verifying it would need a private CA, with its key distributed to the database and its
  certificate to the API container. That is extra secret handling for little gain, because MySQL
  publishes no host port and is reachable only on the internal `data` network (Section 4.2).
- **Revisit:** If the database ever moves off the internal network (for example to a managed
  service on AWS), switch to `sslMode=VERIFY_IDENTITY` with that service's CA.
